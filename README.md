Expense Analyzer
Overview

Smart Expense Analyzer is an AI-powered personal finance project that automatically collects payment history from e-statements stored in your email, extracts transaction data from password-protected PDF statements, and converts it into meaningful financial insights.

The system analyzes spending patterns, categorizes transactions, generates charts and monthly trends, and provides AI-based saving suggestions according to user-defined financial goals. It also supports custom categories for local or unknown merchants to improve accuracy in expense tracking.

Features
Automatic e-statement detection from email
Support for password-protected PDF bank/card statements
Transaction extraction and processing
AI-powered expense categorization
Monthly spending trend analysis
Visual analytics and spending charts
Personalized saving recommendations
Custom merchant/category support
JSON export for complete analysis data
Minimal manual expense tracking



How It Works
The system searches emails for e-statements using predefined keywords.
Matching PDF statements are downloaded securely.
User provides PDF passwords when required.
Transaction data is extracted and cleaned.
AI categorizes expenses automatically.
Spending trends and analytics are generated.
Final analysis is exported as a structured JSON file.

Privacy & Security

User privacy and data security are important parts of this project.

Safety Measures
The application only searches emails using predefined e-statement related keywords written in the code.
No unrelated emails are accessed or processed.
PDF passwords are only used temporarily for statement extraction.
User credentials and sensitive data are not stored permanently.
All analysis is processed locally unless explicitly configured otherwise.
Exported analysis is stored in JSON format for transparency and portability.
No financial data is shared with third parties.
